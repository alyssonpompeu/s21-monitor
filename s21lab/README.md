# S21 Lab Benchmark

Benchmark Android offline e root-aware para o Galaxy S21 SM-G991B / Exynos 2100.

- QUICK: aproximadamente 1 minuto
- FULL: aproximadamente 4–5 minutos
- CPU single/multi
- GPU OpenGL ES offscreen
- RAM bandwidth/latency
- storage read/write
- carga combinada CPU+GPU
- telemetria root de clocks, CAL percent_margin, MIF, thermal/cooling e bateria
- detecção do módulo Magisk g991b_performance_unlock
- capability dump NNAPI/NPU quando disponível
- relatório TXT copiável diretamente para o ChatGPT

O app não altera clocks, voltagens, thermal, módulos ou partições.
