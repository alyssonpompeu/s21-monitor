Política de Privacidade — Wi‑Fi Spectrogram Pro

Última atualização: 10 de agosto de 2026.

Esta Política de Privacidade descreve como o aplicativo Wi‑Fi Spectrogram Pro acessa e trata informações do dispositivo.

1. Dados acessados

O aplicativo acessa informações de redes Wi‑Fi disponibilizadas pelo Android, como nome da rede (SSID), identificador do ponto de acesso (BSSID), frequência, largura de canal e intensidade do sinal (RSSI). Em algumas versões do Android, as APIs de varredura Wi‑Fi exigem as permissões de localização e que o serviço de Localização esteja ativado.

2. Finalidade

Esses dados são usados exclusivamente para gerar, no próprio aparelho, o espectro, o waterfall temporal, a lista de pontos de acesso e as medições de intensidade exibidas ao usuário.

3. Localização

O aplicativo não solicita coordenadas GPS para rastrear o usuário, não cria histórico de localização e não usa informações de Wi‑Fi para acompanhar deslocamentos. As permissões de localização são solicitadas somente quando exigidas pelas APIs de varredura Wi‑Fi do Android.

4. Coleta, compartilhamento e transmissão

O Wi‑Fi Spectrogram Pro não possui conta, login, anúncios, analytics ou SDKs de publicidade. O aplicativo não transmite SSIDs, BSSIDs, localização, medições de sinal ou outros dados de Wi‑Fi para servidores do desenvolvedor ou de terceiros. O processamento é local no dispositivo.

5. Retenção e exclusão

O histórico do espectrograma existe apenas na memória durante o uso do aplicativo e pode ser limpo pelo usuário. O aplicativo não mantém banco de dados remoto nem cadastro de usuários.

6. Segurança

Como o aplicativo não envia os dados analisados para servidores, as informações permanecem no próprio dispositivo, sujeitas às proteções de segurança do Android.

7. Crianças

O aplicativo é uma ferramenta técnica e não é destinado especificamente a crianças.

8. Alterações desta política

Esta política poderá ser atualizada se as funcionalidades ou o tratamento de dados mudarem. A data de atualização será indicada no topo desta página.

9. Contato

Para dúvidas relacionadas à privacidade, use o canal público de suporte do projeto: GitHub Issues.
